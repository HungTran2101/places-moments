# Places Moments

A quiet map of human thoughts.

**Places Moments** is an anonymous, map-based reflection app where people can leave small thoughts tied to locations around the world.

No accounts.
No followers.
No notifications.

Just moments scattered across the planet.

## Idea

Users can drop a message anywhere on Earth and explore messages left by others.

Each message carries a **weather atmosphere** describing the moment it was written.

Example:

> “Posted on a rainy afternoon.”

The goal is not to create a social network, but to create a **space for reflection/special moments**.

## Core Features

* 🌍 Interactive world map
* 📍 Drag a pin to leave a message
* 🌦 Weather-based atmosphere instead of timestamps
* 🧭 Anonymous identity using local UUID
* 🗂 Personal history of your own posts
* ⏳ Send a message to your future self
* ✨ Smooth, modern UI animations

## Tech Stack

* **Next.js** (frontend + backend)
* **PostgreSQL**
* **Prisma ORM**
* **MapLibre GL**
* **GSAP/Framer Motion**

## Philosophy

This project intentionally avoids common social media mechanics.

There are **no likes, comments, followers, or popularity metrics**.

The experience focuses on:

* places
* atmosphere
* reflection
* small human moments
